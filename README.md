# 🤖 ایجنت حقوقی هوشمند (وکیل پایه یک) — راهنمای کامل

ایجنتی که موضوع و مستندات حقوقی را از شما می‌گیرد، در پایگاه دانش قوانین
جمهوری اسلامی ایران جستجو می‌کند (RAG) و به عنوان یک **وکیل پایه یک دادگستری**
تحلیل و راهکار/راهکارهای حقوقی را با استناد دقیق به مواد قانونی پیشنهاد می‌دهد.

---

## 🏗 معماری

```
کاربر (تلگرام)
   │  موضوع (متن) + مستندات (PDF/عکس)
   ▼
doc_processor.py  ──► OCR فارسی / استخراج متن PDF
   │
   ▼
seed_loader.py    ──► جستجوی معنایی در قوانین (chromadb + OpenAI embeddings)
   │  مواد مرتبط
   ▼
lawyer_agent.py   ──► LLM با نقش «وکیل پایه یک» + پرامپت ساختاریافته
   │  تحلیل + استناد + راهکار + هشدار مسئولیت
   ▼
bot.py            ──► ارسال پاسخ به تلگرام
```

---

## ⚙️ پیش‌نیازها (روی ویندوز خودت)

1. **Python 3.11** نصب باشد.
2. **uv** (مدیر بسته): https://github.com/astral-sh/uv
3. توکن ربات تلگرام از [@BotFather](https://t.me/BotFather)
4. کلید OpenAI از https://platform.openai.com/api-keys
5. **اینترنت** (برای دانلود قوانین، مدل‌های OCR و فراخوانی LLM)

## 🚀 نصب و راه‌اندازی (گام‌به‌گام)

### گام ۱ — کلون/کپی پروژه
پوشه `legal_agent` را در جایی روی ویندوز قرار بده (مثلاً `C:\Users\<user>\legal_agent`).

### گام ۲ — ساخت محیط مجازی و نصب پکیج‌ها
در ترمینال (PowerShell یا CMD) داخل پوشه پروژه:
```powershell
uv venv
.venv\Scripts\activate
uv add chromadb openai python-telegram-bot pypdf numpy requests python-dotenv
uv add easyocr pymupdf        # فقط برای OCR تصاویر/PDF اسکن‌شده
```

### گام ۳ — تنظیم کلیدها
فایل `.env.example` را به `.env` کپی کن و مقادیر را پر کن:
```powershell
copy .env.example .env
```
سپس در `.env`:
```
BOT_TOKEN=123456:ABC...
OPENAI_API_KEY=sk-...
MODEL=gpt-4o-mini
```

### گام ۴ — دانلود و تکمیل پایگاه قوانین (مهم‌ترین بخش)
هسته اولیه قوانین از قبل در `data/seed/` هست. برای افزودن کل متن قوانین:
```powershell
python scripts/collect_laws.py
```
این اسکریپت قوانین مدنی/کیفری/آیین دادرسی/تجارت را از منبع عمومی دانلود
و در `data/corpus/collected_laws.jsonl` می‌ریزد.
> اگر سایت در دسترس نبود، نگران نباش — خودت متن قانون را در
> `data/corpus/` به صورت JSONL بچسبان (فرمت در `collect_laws.py` توضیح داده شده).

### گام ۵ — ساخت پایگاه دانش (وکتورایز)
اولین بار که ربات اجرا شود، پایگاه دانش ساخته می‌شود. برای تست جداگانه:
```powershell
python tests/test_local_rag.py
```

### گام ۶ — اجرای ربات
```powershell
python -m src.bot
```
ربات آماده است. در تلگرام:
1. پیام متنی بنویس (موضوع).
2. مستندات را بفرست (اختیاری).
3. `/analyze` بزن.

## 🔒 نکات حقوقی و اخلاقی
- خروجی ایجنت **مشاوره اولیه** است و جایگزین نظر قطعی وکیل دادگستری نیست.
- ربات به صورت خودکار پاراگراف «هشدار مسئولیت» پیوست می‌کند.
- ایجنت فقط به موادی استناد می‌کند که در پایگاه دانش باشند (ضد جعل/هالوسیناسیون).

## 💳 دستورات بات و داشبورد فروش

ایجنت با یک مدل **ترایال → پرداخت** کار می‌کند:

### دستورات کاربر
| دستور | عملکرد |
|-------|---------|
| `/start` | شروع + دریافت نام/شماره (اختیاری) + توضیح ترایال |
| (متن/فایل) | ارسال موضوع و مستندات حقوقی (ایجنت خودش پرسش تکمیلی می‌پرسد) |
| `/analyze` | اجرای تحلیل عمیق + ارسال گزارش کامل به کانال |
| `/draft [نوع]` | صدور سند حقوقی آماده (دادخواست/لایحه/اظهارنامه/شکوائیه/قرارداد) — ویژه کاربران فعال |
| `/buy` | ثبت درخواست خرید (وضعیت «در انتظار تایید» می‌شود) |

کاربر ۱ تحلیل رایگان (ترایال) دارد؛ پس از آن پیام «به @rezapilot پیام بده»
دریافت می‌کند. با `/buy` درخواست ثبت می‌شود و پس از واریز و تایید ادمین،
دسترسی **نامحدود** فعال می‌گردد. **صدور اسناد (`/draft`) فقط برای کاربران
فعال (پرداخت‌شده) است.**

### دستورات ادمین (فقط ADMIN_IDS)
| دستور | عملکرد |
|-------|---------|
| `/admin` | نمایش داشبورد: آمار کاربران + لیست درخواست‌های خرید |
| `/stats` | آمار سریع (کل/پرداختی/ترایال/در انتظار/تحلیل‌ها) |
| `/approve <ID>` | تایید خرید و فعال‌سازی دسترسی نامحدود کاربر |
| `/revoke <ID>` | لغو دسترسی (بازگشت به ترایال) |
| `/broadcast <متن>` | ارسال اطلاعیه در کانال |
| `/draft <نوع>` | تولید سند حقوقی (برای هر کاربری که دسترسی فعال دارد) |

داده‌های کاربران (نام، شماره، وضعیت دسترسی، تعداد تحلیل) در
`data/store.json` ذخیره می‌شوند (این فایل در `.gitignore` لیست شده و هرگز
کامیت نمی‌شود).

## 📄 صدور اسناد حقوقی (`/draft`)
ایجنت پس از تحلیل موضوع، می‌تواند یک سند رسمی و آماده‌ی تسلیم تولید کند:
- **دادخواست**، **لایحه دفاعیه**، **اظهارنامه**، **شکوائیه**، **قرارداد**، **درخواست تأمین دلیل**.
- استنادها فقط از مواد واقعی پایگاه دانش می‌آید (ضد جعل).
- جاهای خالی که اطلاعات کافی نیست با `[ــــــ]` مشخص می‌شود تا کاربر پر کند.
- سند هم به کاربر ارسال می‌شود هم در کانال ثبت می‌گردد.

این قابلیت یک **مسیر پولی‌سازی ثانویه** است: تحلیل رایگان/ارزان، صدور سند
حرفه‌ای پولی.

## 🖥 استقرار دائم روی Render (سرور ۲۴/۷)
ربات برای اجرای دائم روی **Render** آماده‌ست (بدون نیاز به باز بودن لپ‌تاپ):

۱. ریپو را به Render وصلید (https://dashboard.render.com → New → Blueprint →
   انتخاب ریپو). فایل `render.yaml` تنظیمات را خودکار بارگذاری می‌کند.
۲. متغیرهای محیطی را در بخش **Environment** ست کنید:
   - `BOT_TOKEN` (از @BotFather)
   - `OPENAI_API_KEY` (حساب شارژ‌شده)
   - `CHANNEL_ID` (مثلاً `-1004458550016`)
   - `ADMIN_IDS` (مثلاً `67391189,125472442`)
3. روی **Deploy** کلیک کنید. ربات با health-check در مسیر `/healthz` زنده می‌ماند.

نکته: پایگاه وکتور (chroma) روی دیسک Render در `/data/chroma` ذخیره می‌شود
(`DATA_DIR=/data`) و با ری‌استارت از بین نمی‌رود.

برای اجرا روی PC: `run_bot.bat` (ویندوز) یا `python -m src.bot`.

## 📄 خروجی PDF
اسناد تولیدی با `/draft` علاوه بر متن، به صورت **فایل PDF با فرمت حقوقی**
(عنوان موسسه + متن راست‌به‌چپ فارسی با فونت Vazirmatn) به کاربر ارسال می‌شوند.
اگر کتابخانه‌های PDF نصب نباشند، ربات به متن ساده فال‌بک می‌کند. فونت فارسی
به صورت خودکار دانلود می‌شود یا در `data/fonts/persian.ttf` قرار دهید.

## 🛠 گسترش پایگاه دانش
پایگاه دانش فعلی شامل **۱۱۵ ماده** از قوانین زیر است:
قانون مدنی، قانون مجازات اسلامی، قانون مسئولیت مدنی، قانون کار، قانون تجارت،
و آیین دادرسی مدنی/کیفری.

برای افزودن هر قانون جدید، کافی است یک فایل `.jsonl` در `data/seed/` یا
`data/corpus/` با فرمت زیر بسازی:
```json
{"doc_id":"uniq-1","law":"نام قانون","article":"۱۰","title":"عنوان ماده","text":"متن ماده"}
```
ربات در اجرای بعدی آن را به پایگاه دانش اضافه می‌کند (مجموعهٔ کروما پس از
افزودن ماده جدید، با حذف و ساخت مجدد به‌روز می‌شود — برای بازسازی دستی کافی است
پوشهٔ `data/chroma` پاک شود).

## 🗂 ساختار پوشه‌ها
```
legal_agent/
├── src/
│   ├── seed_loader.py     # بارگذاری + وکتورایز قوانین (RAG)
│   ├── doc_processor.py   # OCR + استخراج PDF
│   ├── lawyer_agent.py    # هسته استنتاج + پرامپت وکیل
│   ├── admin_panel.py     # داشبورد فروش + مدیریت دسترسی (store.json)
│   ├── drafter.py         # تولید اسناد حقوقی (دادخواست/لایحه/...)
│   ├── doc_pdf.py         # تولید PDF فارسی (RTL)
│   ├── web_health.py      # health server برای Render
│   └── bot.py             # ربات تلگرام + دستورات + دکمه شیشه‌ای
├── data/
│   ├── seed/              # هسته اولیه قوانین (آماده)
│   ├── corpus/            # قوانین دانلودشده (collect_laws.py)
│   ├── fonts/             # فونت فارسی (persian.ttf)
│   ├── store.json         # داده‌های کاربران (gitignored)
│   └── chroma/            # پایگاه وکتور (خودکار ساخته می‌شود)
├── scripts/
│   └── collect_laws.py    # دانلود انبوه قوانین (روی PC)
├── tests/
│   └── test_local_rag.py  # تست جستجو بدون نیاز به API
├── Procfile               # دستور اجرا روی Render
├── render.yaml            # تنظیمات استقرار Render
└── requirements.txt       # وابستگی‌ها برای pip (Render)
```
